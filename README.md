# Landing Page - Serviços Veterinários

Este é um projeto pessoal desenvolvido como parte de um exercício prático para aprimorar habilidades em **HTML** e **Tailwind CSS**. O resultado é uma landing page moderna e responsiva para serviços veterinários.

## Sobre o Projeto

O objetivo foi criar uma página web de uma única página (one-page) que apresentasse os serviços de uma médica veterinária, incluindo seções como "Sobre Mim", "Serviços" e um formulário funcional de agendamento. O foco principal foi a prática de estilização com classes utilitárias e a estruturação de um layout coeso.

## Funcionalidades

*   **Design Responsivo:** O layout se adapta a diferentes tamanhos de tela, de dispositivos móveis a desktops.
*   **Navegação Suave:** Links de navegação com rolagem suave (`scroll-smooth`) para as seções da página.
*   **Carrossel de Serviços:** Um carrossel interativo (usando Swiper.js) para exibir os serviços oferecidos.
*   **Transições Visuais:** Efeitos de transição em formato de onda entre as seções para uma experiência de usuário mais fluida.
*   **Formulário de Agendamento Funcional:** Um formulário que captura os dados do usuário. O código inclui um exemplo de como enviar os dados para um script do Google Apps, permitindo salvar os agendamentos em uma planilha.

## Tecnologias Utilizadas

*   **HTML5:** Para a estrutura semântica da página.
*   **Tailwind CSS:** Para a estilização rápida e utilitária, permitindo a criação de um design customizado sem escrever CSS tradicional.
*   **JavaScript (ES6):** Para a interatividade, incluindo a inicialização do carrossel e o envio do formulário.
*   **Swiper.js:** Uma biblioteca moderna para criar carrosséis responsivos.
*   **Google Sheets:** Para a integração de dados inseridos no formulário.
